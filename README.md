# TravelVista — Luxury Travel Gallery

A premium responsive travel gallery website built using HTML, CSS, and JavaScript. Designed with a modern luxury UI to showcase beautiful destinations with smooth interactions and elegant visuals.

## Features

- Premium hero section
- Responsive destination gallery
- Interactive image preview modal
- Search functionality
- Category filtering
- Smooth animations
- Mobile responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript
